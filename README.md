# AI-Based Sentiment Analyzer

## Project Description

This project is an AI-based sentiment analysis web application developed using Python, Flask, and Hugging Face Transformers.

The application analyzes user-entered text and classifies it as positive or negative. It also displays the confidence score and stores user interactions in a CSV file.

## Technologies Used

- Python
- Flask
- Hugging Face Transformers
- PyTorch
- HTML
- CSS
- CSV

## Features

- User-friendly web interface
- AI-based sentiment prediction
- Positive and negative sentiment classification
- Confidence score
- Interaction logging
- CSV-based result storage
